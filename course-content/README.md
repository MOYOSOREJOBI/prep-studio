# course-content

Put your own study material in this folder.

Prep Studio is designed to analyze whatever you place here, whether that means:

- one course or many courses
- a flat dump of files
- nested folders by week, topic, module, or lab
- a mix of PDFs, markdown files, notes, code, and references

Examples:

```text
course-content/
├── seng-438/
│   ├── lectures/
│   ├── labs/
│   └── review-notes/
└── math-375/
    ├── assignments/
    └── summaries/
```

or simply:

```text
course-content/
├── lecture-01.pdf
├── lab-02.pdf
├── important-notes.md
└── formulas.tex
```

After adding files, open Prep Studio and click `Analyze Folder`, then select this folder.

This directory is ignored by git except for this README, so your personal course material stays out of the public repo by default.
